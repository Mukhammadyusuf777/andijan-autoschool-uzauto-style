# Andijan Premium Driving School — UzAuto Motors (chevrolet.uz) Style

Официальный образовательный веб-портал автошколы **Andijan Premium** в Андижане, визуально и структурно адаптированный под дизайн-систему официального портала **UzAuto Motors (chevrolet.uz)**.

---

## 🌟 Ключевые особенности проекта

1. **Корпоративная палитра UzAuto Motors:**
   - Фон страниц: `#F8F9FA` и чистый `#FFFFFF`.
   - Глубокий тёмно-синий: `#0B2545` и `#134074`.
   - Фирменные золотые акценты и кнопки: `#DCA626` / `#EAA023` (Chevrolet Gold).
   - Строгая деловая типографика (Inter) без неона и размытий.

2. **Главный экран (Hero Slider — «Учителя вместо машин»):**
   - Полноэкранный слайдер с преподавателями высшей категории (Алишер Каримов, Елена Дмитриева, Сардор Махмудов, Бобур Юсупов).
   - Финансово-гарантийные блоки в стиле кредитных предложений Chevrolet:
     - **0% СТРАХА**
     - **12 месяцев СОПРОВОЖДЕНИЯ**
     - **98% СДАЧИ С ПЕРВОГО РАЗА**

3. **Секция «Курсы и категории» (Модельный ряд):**
   - Интерактивная дилерская сетка с карточками учебных автомобилей (Chevrolet Cobalt, Gentra, Isuzu NPR, Tracker, Onix Turbo, Мотоциклы).
   - Подробные спецификации: часы вождения, теория, коробка передач, условия беспроцентной рассрочки.

4. **Интерактивный финансовый калькулятор:**
   - Расчет стоимости обучения в рассрочку 0%: выбор курса, первоначального взноса (0%, 20%, 30%, 50%) и срока (3, 6, 12 месяцев) с моментальным расчетом ежемесячного платежа.

5. **Филиалы и интерактивная карта Андижана:**
   - 4 локации (Центральный, Вокзал, Старый город, Автодром Богишамол).
   - Интеграция с Leaflet с фирменными маркерами и центрированием по клику.

6. **Двуязычный интерфейс:**
   - Основной язык по умолчанию: **Русский (RU)**.
   - Второй язык: **O'zbekcha (UZ)**.
   - Мгновенное переключение языка всех элементов без перезагрузки страницы.

---

## 🚀 Локальный запуск

Проект создан на чистом стеке (HTML5, Tailwind CSS, JavaScript ES6+, Leaflet, FontAwesome). Для запуска достаточно любого локального веб-сервера.

```bash
# Вариант 1: С помощью npx serve
npx serve .

# Вариант 2: С помощью Python
python -m http.server 8000
```

## 🌐 Деплой на Cloudflare Pages

1. **Создайте репозиторий на GitHub:**
   - Название: `andijan-autoschool-uzauto-style`
   
2. **Отправьте код в репозиторий:**
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of uzauto motors style autoschool website"
   git branch -M main
   git remote add origin https://github.com/Mukhammadyusuf777/andijan-autoschool-uzauto-style.git
   git push -u origin main
   ```

3. **В панели Cloudflare Dashboard:**
   - Перейдите в **Workers & Pages** -> **Create application** -> **Pages**.
   - Нажмите **Connect to Git** и выберите репозиторий `andijan-autoschool-uzauto-style`.
   - **Framework preset:** `None` (Static HTML).
   - **Build command:** оставить пустым.
   - **Build output directory:** `/` (корень).
   - Нажмите **Save and Deploy**.
   - Ваш сайт мгновенно станет доступен по бесплатному адресу `https://andijan-autoschool-uzauto-style.pages.dev`!
